# Task 3 — Volunteering & Internship Opportunities for Students in India

## File
`BhaktiMisal_Task3.csv`

## Description
A structured database of 20+ volunteering, internship, and fellowship opportunities available to students across India — including National Service Scheme (NSS), Teach For India, Gandhi Fellowship, Goonj, Robin Hood Army, CRY, Pratham, Smile Foundation, and more.

Each entry includes:
- Organization name
- Opportunity type (volunteering / internship / fellowship)
- Eligibility criteria
- Application link
- Deadline

## Purpose
Built as part of the InAmigos Foundation (IAF) volunteering journey, so students don't have to spend hours searching across scattered sources to find social-impact opportunities.
